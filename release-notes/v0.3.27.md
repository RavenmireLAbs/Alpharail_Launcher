## What's new

- Added **Launcher settings → System → Diagnostics** with optional local navigation logging, a reproduction marker, export to a text file, and log clearing.
- Logs record activity lifecycle, Home-intent delivery, window focus, and panel attachment/detachment, along with timestamps and basic device/app version information.
- Logging is off by default. Files stay in private app storage with bounded rotation (roughly 128 KB); nothing is uploaded automatically. Messages, search text, and app lists are not recorded.

## Using diagnostics

Enable local navigation logs, reproduce the issue, optionally add a marker, then export the log. Turn logging off when finished. Clearing local logs does not delete exported copies.

This release adds diagnostics, not a fix for system Recents behavior. It cannot record the system's internal Recents events.
