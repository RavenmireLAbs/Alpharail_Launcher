## What's new

- Optional Work apps section on Home for available managed-profile apps.
- Optional app notification dots with per-app exclusions. Requires Android notification access; dots indicate active, non-ongoing notifications, not unread counts.
- When app search has no matches, search the web or Play Store, or open a valid web link.
- Scheduled White/Black appearance using configurable start hours. Wallpaper mode stays unchanged.
- Accessibility options for larger alphabet labels, reduced letter-popup animations, and stronger wallpaper text shadows.

Find the new controls under **Launcher settings → App list → More options**. Existing backup export/import and restore confirmation remain available.

## Notes

- Sunset-based scheduling and browser-preview updates for these features are not included.
- Build and APK signature verification passed; the new features have not yet been tested on-device. Work-profile availability depends on Android profile settings and policy.
