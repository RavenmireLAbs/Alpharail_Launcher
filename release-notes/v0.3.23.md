## What's changed

- Reorganized Launcher settings into seven sections: Appearance, Home & apps, Notifications & Chats, Privacy, Accessibility, Backup and restore, and System.
- Removed the catch-all More options menu and grouped related controls together without changing saved preferences.
- Theme scheduling now saves and displays minutes as well as hours. Both normal and overnight schedules use the selected minute accurately.
- Added a Work apps management dialog with show/hide controls, an Android account-settings shortcut, and guidance about managed work profiles versus personal-app Collections.

## Validation

Native build and APK signature verification passed. These changes have not yet been tested on-device. The browser preview has not been updated to the reorganized settings.
