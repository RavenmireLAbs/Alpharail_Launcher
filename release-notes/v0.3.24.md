## What's changed

- Theme scheduling now uses an AM/PM time picker and display while preserving minutes.
- Enabling scheduling while wallpaper is on asks permission to switch Alpharail to solid backgrounds. The Android wallpaper is not replaced. Scheduling remains paused while wallpaper mode is on.
- Settings lists and choice pages now use full-screen panels with Back navigation. Specialized pickers, previews, and confirmation dialogs remain compact.
- Hardware Back on settings panels returns to the parent section.

## Validation

Native build and APK signature verification passed. These changes have not yet been tested on-device.
