## What's changed

- Full-screen settings pages now display inside Alpharail's main activity window instead of separate dialog windows.
- Home actions close inline settings, while Back returns to the parent settings section.
- Wallpaper remains visible behind settings without Home labels or icons. Compact pickers and confirmation dialogs remain separate.
- Local diagnostics now record inline settings opening and closing.

## Validation

Native build and APK signature verification passed. On-device confirmation is pending. This change targets settings-to-Home transitions; it does not claim to fix empty Recents or system launcher animations.
